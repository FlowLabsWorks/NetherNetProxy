NetherNetProxy is licensed under the MIT License (see `LICENSE`). The binary statically links the
following third-party Go modules (versions as pinned in `go.mod`) and the Go standard library
(BSD-3-Clause, Copyright The Go Authors, https://go.dev/LICENSE).

| Module | License |
| --- | --- |
| github.com/pion/dtls/v3 | MIT |
| github.com/pion/sctp | MIT |
| github.com/pion/transport/v5 | MIT |

| golang.org/x/sys | BSD-3-Clause |

`golang.org/x/net` is listed in `go.mod` as an indirect requirement but is not linked into the
binary.

Protocol formats were implemented with the help of the specifications and code of
[df-mc/nethernet-spec](https://github.com/df-mc/nethernet-spec) and
[df-mc/go-nethernet](https://github.com/df-mc/go-nethernet) (both MIT); no code of those projects is
included. STUN test vectors in `cmd/nethernet-proxy/proxy_test.go` are taken from RFC 5769 (code components of RFCs
are provided under the Revised BSD License per the IETF Trust's Legal Provisions).

The Bedrock packet templates in `cmd/nethernet-proxy/bedrock.go` are recordings of protocol messages (the server side of
a join), captured during development with a listener built on
[Sandertv/gophertunnel](https://github.com/Sandertv/gophertunnel) (MIT). They are protocol data, not
program code, and no gophertunnel code is included.
