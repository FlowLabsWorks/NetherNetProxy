# Getting help

NetherNetProxy is a small hobby project maintained in spare time, so answers can take a while.

- **Something does not work:** read **Troubleshooting** in the [README](README.md) first, run the
  proxy with `-check` and `-v`, then open a
  [bug report](https://github.com/FlowLabsWorks/NetherNetProxy/issues/new?template=bug_report.yml).
  Remove host names and addresses you do not want to publish before posting logs.
- **A new Minecraft version broke the join:** see [docs/UPDATING.md](docs/UPDATING.md). The
  repository watches Mojang's protocol documentation and opens an issue when a packet the proxy
  uses changes; check the open issues for your version.
- **Ideas and questions about how it works:** open an
  [issue](https://github.com/FlowLabsWorks/NetherNetProxy/issues/new/choose) or read
  [docs/HOW-IT-WORKS.md](docs/HOW-IT-WORKS.md).
- **Security problems:** report them privately, see [SECURITY.md](SECURITY.md).
